## 🚀 Cara Menggunakan

1. Buka file `index.html` di browser
2. Customize content sesuai dengan data Anda
3. Modify warna di CSS `:root` variables
4. Tambahkan gambar/portfolio items sesuai kebutuhan

## 💡 Tips Customization

### Mengubah Warna
Edit di bagian `:root` di `styles.css`:
```css
:root {
    --primary-color: #6366f1;
    --secondary-color: #10b981;
    /* dst */
}
```

### Menambah Portfolio Items
Tambahkan `portfolio-card` baru di HTML:
```html
<div class="portfolio-card">
    <div class="card-image"></div>
    <h3>Project Name</h3>
    <p>Project description</p>
</div>
```

### Mengubah Font
Ubah di CSS `body`:
```css
font-family: 'Your Font Name', sans-serif;
```
